세 가지 방식, 하나의 선택

기존 React 코드 자산을 최대한 활용하는 방식을 선택했습니다.

🌐 PWA

Progressive Web App

✅ 장점

  • 추가 코드 거의 없음
  • VitePWA 이미 설정됨
  • Android TWA로 Play Store 등록 가능

❌ 단점

  • iOS App Store 출시 불가
  • 네이티브 API 제한
iOS 포기 시에만 유효
✅ 권장

⚡ Capacitor

Ionic Capacitor

✅ 장점

  • 기존 React 코드 100% 재사용
  • Android + iOS 동시 지원
  • 네이티브 API 플러그인 추가 가능
  • Supabase 수정 없이 동작

⚠️ 고려사항

  • iOS 빌드에 Mac 또는 클라우드 필요
DTS에 최적의 선택

📦 React Native

Expo 포함

✅ 장점

  • 진정한 네이티브 성능
  • Android + iOS 동시 지원

❌ 단점

  • 기존 코드 거의 전부 재작성
  • DOM 기반 → RN 컴포넌트 변환
  • 개발 기간 3~6개월 추가

5주 만에 첫 앱 출시

LESSON:ON Android를 시작으로, 이후 앱은 1/5 공수로 순차 출시합니다.

WEEK 1
환경 세팅
Google Play Console 가입 ($25) Apple Developer 가입 ($99/년) Capacitor 설치 Android 빌드 확인
WEEK 2
LESSON:ON Android 준비
.env.lesson-on 작성 앱 아이콘 512×512 스크린샷 5장 개인정보처리방침 페이지 키스토어 생성
WEEK 3
✅ Android 출시
AAB 서명 빌드 내부 테스트 제출 심사 승인 (1~3일) Google Play 정식 출시
WEEK 4
iOS 준비
Codemagic 클라우드 빌드 설정 코드 서명 인증서 App Store Connect 앱 생성 iPhone 스크린샷 (1320×2868)
WEEK 5
✅ iOS 출시
TestFlight 내부 테스트 App Store 심사 제출 심사 승인 (1~7일) App Store 정식 출시

나머지 버티컬 앱 순차 출시
