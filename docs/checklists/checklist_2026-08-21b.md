# 2026-08-21 결제 기록 화면 개선 체크리스트

테스트 환경: http://localhost:5173
테스트 계정: 레슨온 관리자 (복수 결제 기록이 있는 조직)

---

## 1. 상태 필터 탭

배경: 차감완료·만료 건이 활성 건과 섞여 현황 파악이 어려웠음.
결제 기록 테이블 위에 상태별 필터 탭을 추가해 구분.

- [ ] 탭 바 표시 확인 — 전체 / 진행중 / 만료임박 / 만료 / 사용완료
- [ ] 각 탭에 건수 뱃지가 정확히 표시되는지 확인
- [ ] 탭 선택 시 해당 상태의 레슨권만 필터링되는지 확인
- [ ] 회원 필터(드롭다운)와 상태 탭을 동시에 적용했을 때 AND 조건으로 동작하는지 확인
- [ ] 건수가 0인 탭도 비활성화 없이 선택 가능한지 확인 (빈 목록 메시지 표시)

---

## 2. 사용완료·만료 행 시각적 구분

배경: 완료된 레슨권이 활성 건과 동일하게 표시되어 구분이 어려웠음.

- [ ] 사용완료(차감 = 총 횟수) 행이 흐리게(opacity-55) 표시되는지 확인
- [ ] 만료 행이 흐리게 표시되는지 확인
- [ ] 진행중·만료임박 행은 정상 불투명도로 표시되는지 확인

---

## 3. 회원별 그룹 뷰

배경: 동일 회원의 복수 결제권이 목록에 분산되어 현황 파악이 어려웠음.

- [ ] 결제 기록 헤더에 **목록 / 회원별** 토글 버튼 표시 확인
- [ ] 회원별 뷰 전환 시 회원 이름으로 그룹 헤더 행 표시 확인
- [ ] 그룹 헤더에 진행중·만료임박·완료/만료 건수 뱃지 및 잔여 n회·n건 표시 확인
- [ ] 헤더 클릭 시 해당 회원의 개별 레슨권 행 펼치기/접기 동작 확인
- [ ] 펼친 행에서 레슨종류·결제일·만료일·차감·상태·삭제 컬럼 정상 표시 확인
- [ ] 회원별 뷰에서 상태 필터 탭이 동일하게 동작하는지 확인
- [ ] 회원별 뷰에서 회원 필터 드롭다운 사용 시 해당 회원 그룹만 표시 확인
- [ ] 목록 뷰로 다시 전환 시 기존 테이블이 정상 표시되는지 확인

---

## 4. 회귀 테스트

- [ ] 결제 기록 삭제 정상 동작 확인
- [ ] 만료 임박 알림 배너 및 문자 발송 모달 정상 동작 확인
- [ ] 레슨 종류 추가/수정/삭제 정상 동작 확인
