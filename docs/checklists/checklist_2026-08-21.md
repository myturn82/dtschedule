## 1. 회원 추가 — 다른 조직 이메일 조회 수정

배경: `profiles` RLS(`profiles_select_same_tenant`)가 같은 조직 멤버만 조회를 허용해,
다른 조직에 이미 가입된 사용자의 이메일을 입력하면 "해당 이메일로 가입된 사용자가 없습니다" 오류가 발생했음.
`find_profile_by_email` SECURITY DEFINER RPC로 RLS를 우회해 이메일 전체 검색이 가능해짐.

- [ ] 관리자 콘솔 → 회원 관리 → 회원 추가 폼 열기
- [ ] 현재 조직 소속 이메일 입력 → "이미 소속된 회원입니다" 또는 성공 메시지 확인
- [ ] 다른 조직에 가입된 이메일(예: `test73@test.com`) 입력 → 오류 없이 회원 추가 성공
- [ ] 존재하지 않는 이메일 입력 → "해당 이메일로 가입된 사용자가 없습니다" 오류 표시
- [ ] 슈퍼관리자 이메일 입력 → "슈퍼관리자 계정은 조직에 추가할 수 없습니다" 오류 표시
- [ ] **[DB 확인]** 추가 성공 시 `tenant_members` 테이블에 해당 `user_id`·`tenant_id` 행 생성 확인
