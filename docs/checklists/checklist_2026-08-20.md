# 2026-08-20 변경사항 점검 체크리스트

테스트 환경: http://localhost:5173
테스트 계정: `attendance` feature flag가 켜진 조직의 관리자 계정

---

## 사전 준비

- [ ] **[DB 확인]** 개발 DB `assignments` 테이블에 `attended_at timestamptz` 컬럼 존재 확인
- [ ] **[슈퍼관리자]** 테스트 조직의 `feature_flags.attendance = true` 설정 확인
  - 슈퍼관리자 → 조직 드로어 → 기능 플래그 → "출석 체크" 체크박스 ON

---

## 1. 출석 체크 버튼 노출 조건

- [ ] `attendance` FF **ON** 조직 → 관리자 계정으로 슬롯 팝업 열기 → 배정 행에 체크 아이콘 버튼이 표시됨
- [ ] `attendance` FF **OFF** 조직 → 슬롯 팝업 열기 → 체크 버튼이 **표시되지 않음**
- [ ] 동일 조직에서 **일반 멤버 계정**으로 로그인 → 체크 버튼이 **표시되지 않음** (관리자 전용)

---

## 2. 출석 체크 버튼 동작 — 출석 확인

- [ ] 슬롯 팝업 → 배정 행의 체크 버튼 클릭 (미출석 상태)
- [ ] 버튼이 초록색(emerald)으로 변경됨
- [ ] 배정 행 이름 옆에 **"출석"** 초록 뱃지가 나타남
- [ ] **[DB 확인]** `assignments` 테이블 해당 row의 `attended_at`에 타임스탬프 값이 저장됨

---

## 3. 출석 체크 버튼 동작 — 출석 취소

- [ ] 이미 출석 처리된 배정 행의 체크 버튼(초록) 재클릭
- [ ] 버튼이 기본 색(회색)으로 복원됨
- [ ] **"출석"** 뱃지가 사라짐
- [ ] **[DB 확인]** `attended_at` 값이 `null`로 초기화됨

---

## 4. 슬롯 팝업 재오픈 시 상태 유지

- [ ] 출석 처리 후 팝업을 닫고 동일 슬롯 재클릭
- [ ] 출석 처리한 배정 행에 초록 뱃지와 초록 버튼이 그대로 표시됨 (새로고침 후에도 유지)

---

## 5. AdminPage — 출석 현황 탭 노출 조건

- [ ] `attendance` FF **ON** 조직 → 관리자 콘솔에 **"출석 현황"** 탭이 표시됨
- [ ] `attendance` FF **OFF** 조직 → "출석 현황" 탭이 **표시되지 않음**

---

## 6. AdminPage — 출석 현황 탭 기본 동작

- [ ] "출석 현황" 탭 클릭 시 헤더와 시작일·종료일 입력 필드 표시됨
- [ ] 기본값이 이번 달 1일~말일로 설정되어 있음
- [ ] 해당 기간에 배정 이력이 있는 경우 사용자별 테이블이 표시됨
- [ ] 테이블 컬럼: **이름 / 총 배정 / 출석 / 출석률**
- [ ] 출석률 색상:
  - [ ] 80% 이상 → 초록(emerald)
  - [ ] 50~79% → 노랑(amber)
  - [ ] 49% 이하 → 빨강(red)
- [ ] 합계 행이 테이블 하단에 표시되고 건수·출석 수·출석률 합산이 올바름
- [ ] 해당 기간 배정 이력 없을 시 "해당 기간에 배정 이력이 없습니다." 메시지 표시

---

## 7. AdminPage — 출석 현황 탭 날짜 범위 변경

- [ ] 시작일 변경 시 자동으로 데이터 재조회됨
- [ ] 종료일 변경 시 자동으로 데이터 재조회됨
- [ ] 여러 달에 걸친 기간 지정 시 (예: 2026-07-01 ~ 2026-08-31) 누적 출석 데이터가 합산됨
- [ ] 결과가 출석 건수 기준 내림차순으로 정렬됨
