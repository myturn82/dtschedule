# 2026-07-28 변경사항 점검 체크리스트

## 1. 플랜 표시에서 금액 제거

배경: 구독 결제 로직이 아직 없는 상태라 금액을 표시하면 실제 결제가 가능한 것처럼 오해할 수 있어, 결제 로직이 붙기 전까지 플랜 이름만 노출하도록 변경.

- [ ] 슈퍼관리자 → 고객 계정 허브에서 요금제 드롭다운(Basic/Pro/Business)에 금액이 표시되지 않는지 확인
- [ ] 슈퍼관리자 → "플랜 한도 설정" 표에 플랜명만 표시되고 금액이 없는지 확인
- [ ] 조직 관리자 화면 상단 "현재 플랜" 배지에 금액이 표시되지 않는지 확인 (`Basic`/`Pro`/`Business`)
- [ ] 조직 수 한도 초과 시 뜨는 안내 메시지("현재 플랜(...)의 최대 조직 수...")에 금액이 없는지 확인
- [ ] 회원 수 한도 초과 시 뜨는 안내 메시지에 금액이 없는지 확인

## 2. 레슨권 만료 임박 알림 문자 발송 (소진 독려)

배경: 결제 후 레슨권을 다 사용하지 않은 채 만료일이 다가오는 회원을 관리자가 놓치기 쉬워, 만료가 임박한 미소진 회원을 자동으로 찾아 일괄/개별로 "소진 독려" 문자(SMS)를 보낼 수 있는 기능 추가. 만료 도래 기준(1주일/2주일/n일 전)은 관리자가 직접 선택 가능.

- [ ] 관리자콘솔 → 레슨권 관리 탭 상단에 "⏰ 만료 임박 레슨권 미소진 회원 N명" 배너가 항상 표시되는지 확인
- [ ] 배너의 "만료 도래 기준"에서 "1주일 전" 선택 시, 오늘부터 7일 이내(당일 포함) 만료 예정이면서 아직 다 소진되지 않은 회원만 카운트되는지 확인
- [ ] "2주일 전" 선택 시 14일 이내 기준으로 카운트가 바뀌는지 확인
- [ ] "직접입력" 선택 후 숫자를 입력하면 해당 일수 기준으로 카운트가 바뀌는지 확인 (예: 3일 입력 시 3일 이내만)
- [ ] 이미 만료일이 지난(과거) 회원은 대상에서 제외되는지 확인 (이 기능은 "만료 전" 소진 독려가 목적)
- [ ] 레슨권을 완전히 소진(사용 횟수 = 총 횟수)한 회원은 만료 임박 여부와 무관하게 대상에서 제외되는지 확인
- [ ] 대상이 0명이면 "📱 문자 발송" 버튼이 비활성화되는지 확인
- [ ] "📱 문자 발송" 버튼 클릭 시 모달이 열리고, 대상 회원 목록(이름·전화번호·레슨종류·D-day·만료일·잔여 횟수)이 표시되는지 확인
- [ ] "전체 선택/전체 해제" 토글이 정상 동작하는지 확인
- [ ] 개별 회원 체크박스를 해제하면 해당 회원이 발송 대상에서 제외되는지 확인 (개별 발송)
- [ ] 전화번호 입력란을 직접 수정할 수 있고, 수정한 번호로 발송 대상에 반영되는지 확인
- [ ] 전화번호가 없는 회원은 선택되어도 "문자 발송" 버튼의 대상 인원수에서 제외되고 안내 문구가 뜨는지 확인
- [ ] 메시지를 입력한 뒤 "📱 문자 발송 (N명)" 버튼 클릭 시 기기의 문자(SMS) 앱이 선택된 번호들로 열리는지 확인 (모바일 환경에서 확인 필요)
- [ ] 메시지가 비어 있거나 대상이 0명이면 발송 버튼이 비활성화되는지 확인
