## 1. 위자드 레슨종류 설정 단계 (LESSON:ON / CLASS:ON)

배경: LESSON:ON·CLASS:ON 버티컬 가입 시 레슨권 종류를 위자드에서 바로 등록할 수 있도록 step 6에 레슨종류 설정 단계 추가. 커스텀필드는 step 7로 이동.

### LESSON:ON 버티컬 (`?vertical=lesson-sports`)

- [ ] `/setup?org=<org-id>&vertical=lesson-sports` 접속 시 위자드가 7단계로 표시됨 (dots 7개)
- [ ] step 5(운영규칙) 완료 후 "다음" 클릭 시 step 6에 레슨종류 설정 화면이 나타남
- [ ] step 6 상단에 sparkles 아이콘과 "레슨 종류를 등록해주세요" 타이틀이 표시됨
- [ ] 레슨 종류 이름 + 회차 수 입력 후 "레슨 종류 추가" 클릭 시 목록에 즉시 추가됨
- [ ] **[DB 확인]** Supabase `lesson_package_types` 테이블에 추가한 레슨 종류가 저장됨
- [ ] 유효 기간(주) 입력 시 목록에 `{회차}회 · {주}주` 형태로 표시됨
- [ ] 유효 기간을 비워도 레슨 종류 추가 가능 (선택 항목)
- [ ] 목록의 삭제 버튼 클릭 시 해당 항목이 목록에서 즉시 제거됨
- [ ] **[DB 확인]** 삭제 후 Supabase `lesson_package_types` 테이블에서도 삭제됨
- [ ] 레슨 종류 미등록 상태에서 "다음" 클릭 시 step 7(커스텀필드)로 이동함 (필수 아님)
- [ ] step 6에 "건너뛰기" 버튼이 표시됨
- [ ] "건너뛰기" 클릭 시 step 7(커스텀필드)로 이동함
- [ ] step 7에서 커스텀필드 설정 후 "완료하기" 클릭 시 위자드가 정상 완료됨
- [ ] "나중에 관리자 화면에서 언제든 추가·수정할 수 있어요." 안내 문구가 표시됨

### CLASS:ON 버티컬 (`?vertical=education-academy`)

- [ ] `/setup?org=<org-id>&vertical=education-academy` 접속 시 위자드가 7단계로 표시됨
- [ ] step 6에 레슨종류 설정 화면이 나타남
- [ ] 레슨 종류 추가·삭제 정상 동작

## 2. 회귀 테스트 (기존 기능 영향 확인)

### 일반 조직 위자드 (버티컬 없음)

- [ ] `?vertical` 파라미터 없이 접속 시 위자드가 6단계로 표시됨 (기존과 동일)
- [ ] step 5(운영규칙) 완료 후 "다음" 클릭 시 바로 step 6(커스텀필드)가 나타남 (레슨종류 단계 없음)
- [ ] 비회원 모드에서 step 6 커스텀필드가 필수로 동작함 (건너뛰기 없음)
- [ ] 회원 모드에서 step 6 커스텀필드에 "건너뛰기" 버튼이 표시됨

### 기타 버티컬 (SHIFT:ON, SERVE:ON 등)

- [ ] `?vertical=food-retail` 접속 시 위자드가 6단계로 표시됨 (레슨종류 단계 없음)

### 기존 조직 위자드 재진입

- [ ] 이미 생성된 조직의 위자드 재진입(`?org=<id>`, `vertical` 파라미터 없음) 시 6단계 그대로 표시됨
