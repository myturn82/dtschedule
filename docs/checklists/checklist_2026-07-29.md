## 1. 자체 피드백 게시판 (Tally 대체)

배경: 외부 Tally 폼 대신, 회원/조직관리자가 앱 안에서 시스템관리자 또는 조직관리자에게 문의를 등록하고
답변받을 수 있는 자체 게시판을 새로 만들었다. 단순문의(예약변경 등)는 조직관리자에게, 오류신고·기능개선은
시스템관리자에게 자동으로 라우팅된다.

### 1-1. 문의 등록 (일반 멤버 기준)

- [ ] 헤더의 "피드백"(💬) 버튼 클릭 시 모달이 열리는지 확인
- [ ] "새 문의 작성" 탭에서 문의 유형 3가지(단순 문의/오류 신고/기능 개선) 선택 시 설명 문구가 각각 다르게 보이는지 확인
- [ ] 제목·내용 없이 등록 시도하면 "제목과 내용을 입력해 주세요." 오류가 뜨는지 확인
- [ ] 스크린샷 첨부(최대 3장) 후 등록 시 정상적으로 업로드되는지 확인 (개당 500KB 내외로 압축되는지 개발자도구 네트워크 탭에서 확인)
- [ ] 등록 완료 시 "문의가 등록됐습니다." 안내와 "내 문의 내역 보기" 링크가 뜨는지 확인
- [ ] "내 문의 내역" 탭에서 방금 등록한 문의가 "답변대기" 상태로 보이는지 확인
- [ ] 조직을 선택하지 않은 상태(조직 미소속/미선택)에서는 "조직을 먼저 선택해 주세요." 안내만 뜨고 등록 폼이 안 보이는지 확인

### 1-2. 단순 문의 → 조직 관리자 라우팅

- [ ] 멤버 계정으로 "단순 문의" 등록
- [ ] 같은 조직의 관리자 계정으로 로그인 → 관리자콘솔 → "피드백" 탭에 방금 등록한 문의가 "답변대기"로 보이는지 확인
- [ ] 관리자 헤더의 피드백 버튼에 빨간 배지 숫자가 1 이상 뜨는지 확인
- [ ] 다른 조직의 관리자 계정으로는 이 문의가 보이지 않는지 확인 (조직 스코프 검증)
- [ ] 관리자가 답변 등록 → 상태가 "답변완료"로 바뀌는지, 배지 숫자가 줄어드는지 확인
- [ ] 멤버 계정으로 돌아가 알림(🔔) 벨에 "문의에 답변이 등록됐습니다" 알림이 오는지 확인
- [ ] 멤버가 "내 문의 내역"에서 추가로 문의(후속 질문) 등록 → 상태가 다시 "답변대기"로 바뀌는지 확인

### 1-3. 오류신고·기능개선 → 시스템 관리자 라우팅

- [ ] 멤버 또는 관리자 계정으로 "오류 신고" 또는 "기능 개선" 등록
- [ ] 슈퍼관리자 계정으로 로그인 → 슈퍼관리자 화면 → "피드백" 탭에 문의가 보이는지 확인 (조직명이 함께 표시되는지)
- [ ] 슈퍼관리자 헤더의 피드백 버튼에 배지 숫자가 뜨는지 확인
- [ ] 해당 조직의 관리자 계정(슈퍼관리자 아님)에게는 이 문의가 "피드백" 탭에 보이지 않는지 확인 (target_type 분리 검증)
- [ ] 슈퍼관리자가 답변 등록 → 작성자에게 알림이 가는지 확인

### 1-4. 상태 관리 · 필터

- [ ] "피드백" 탭에서 답변대기/답변완료/종료/전체 필터 버튼으로 목록이 필터링되는지 확인
- [ ] "문의 종료 처리" 버튼 클릭 시 상태가 "종료"로 바뀌는지 확인

### 1-5. 도움말 페이지 연동

- [ ] 도움말 센터(`/help`) 하단 "피드백 보내기" 클릭 시 (외부 Tally가 아니라) 같은 인앱 모달이 열리는지 확인

## 2. 시스템관리자 문의내역 삭제 기능

배경: 슈퍼관리자 콘솔의 피드백(문의내역) 게시판에서 불필요/스팸성 문의를 정리할 수 있는 삭제 기능이 없었다.

- [ ] 슈퍼관리자로 로그인 → 슈퍼관리자 콘솔 → "피드백" 탭 진입
- [ ] 문의 목록의 각 항목을 펼치면 하단에 "삭제" 버튼(빨간색)이 보인다
- [ ] "삭제" 클릭 시 확인창이 뜨고, 취소하면 삭제되지 않는다
- [ ] 확인 후 삭제하면 목록에서 즉시 사라진다
- [ ] 답변이 달려있던 문의를 삭제해도 에러 없이 정상 삭제된다 (답변도 함께 삭제)
- [ ] **[DB 확인]** `feedback_posts`에서 해당 행이 삭제되고, `feedback_replies`도 cascade로 함께 삭제됨
- [ ] 일반 조직관리자 콘솔("관리자콘솔 → 피드백" 탭)에는 삭제 버튼이 보이지 않는다 (시스템관리자 전용)

## 3. 관리자 답변 입력창 줄바꿈 지원 & 문의 등록 완료 화면 개선

배경: 관리자 답변 입력창이 단일행 input이라 Enter 시 바로 제출돼 줄바꿈이 불가능했고, 문의 등록 완료 화면의
"내 문의 내역 보기"만 있어 등록 직후 이어서 새 문의를 작성하기 불편했다.

- [ ] 관리자콘솔/슈퍼관리자 "피드백" 탭에서 답변 입력 시 Enter로 줄바꿈이 되고, 제출은 "답변" 버튼 클릭으로만 되는지 확인
- [ ] 여러 줄로 작성한 답변이 등록 후 줄바꿈 그대로 표시되는지 확인
- [ ] 문의 등록 완료 화면에서 "새 문의 작성"(채운 버튼)과 "내 문의 내역 보기"(테두리 버튼)가 눈에 띄게 표시되는지 확인
- [ ] "새 문의 작성" 클릭 시 등록 폼으로 돌아가 바로 새 문의를 작성할 수 있는지 확인

## 4. 조직관리자용 단순 문의를 시스템관리자에게도 항상 노출

배경: '단순 문의'는 조직관리자에게만 라우팅되는데, 문의를 등록한 조직관리자 본인이 해당 조직의
유일한 승인 관리자인 경우 아무도 확인해줄 사람이 없는 사각지대가 있었다. RLS는 이미 시스템관리자에게
전체 조회 권한이 있었으므로(`is_super_admin_caller()`), 앱 쿼리의 `target_type` 필터를 없애 시스템관리자
화면에 조직관리자용 단순 문의도 항상 함께 노출하도록 수정했다.

- [ ] 일반 멤버(또는 조직관리자) 계정으로 "단순 문의" 등록
- [ ] 슈퍼관리자 계정으로 로그인 → "피드백" 탭에 방금 등록한 단순 문의가 보이는지 확인 (기존에는 오류신고/기능개선만 보였음)
- [ ] 해당 문의 항목에 "조직관리자용" 회색 배지가 상태 배지 옆에 표시되는지 확인
- [ ] 슈퍼관리자 헤더의 피드백 배지 숫자에 단순 문의(답변대기)도 포함되어 카운트되는지 확인
- [ ] 슈퍼관리자가 조직관리자용 단순 문의에 직접 답변을 등록할 수 있는지 확인 (RLS 상 허용됨)
- [ ] 오류신고·기능개선 문의는 기존과 동일하게 "조직관리자용" 배지 없이 표시되는지 확인
- [ ] 조직관리자 콘솔("관리자콘솔 → 피드백" 탭)에는 여전히 자기 조직의 단순 문의만 보이는지 확인 (다른 조직 문의 노출 안 됨 — org 스코프는 변경 없음)

1. **1-2번** 단순 문의 → 조직 관리자 라우팅 — 조직 경계를 넘어 문의가 보이면 안 되므로 가장 중요

7. **N번** 회귀 테스트
