# 변경 테스트 체크리스트 — 2026-08-30

## 작업 내용
기존 등록된 스케줄 수정 시 날짜 및 시간대 변경 기능 추가 (관리자 전용)

## 테스트 환경
- [ ] 관리자 계정으로 로그인
- [ ] 스케줄이 등록된 날짜 셀 클릭

---

## 기능 테스트

### 1. 수정 폼 UI 표시 확인
- [ ] 등록된 스케줄의 **수정** 버튼 클릭 시 편집 폼 상단에 "날짜 변경" 버튼이 표시된다
- [ ] "시간대 변경" 버튼 그룹이 표시되며, 현재 배정된 시간대가 선택(활성) 상태이다
- [ ] 비관리자(일반 회원)로 로그인 시 날짜/시간대 변경 UI가 **표시되지 않는다**

### 2. 날짜 변경
- [ ] "날짜 변경" 버튼 클릭 시 스크롤 달력(DatePickerModal)이 열린다
- [ ] 달력에서 다른 날짜(예: 10일 → 15일) 선택 후 확인 클릭 시 버튼 텍스트가 바뀌고 "(변경됨)" 표시가 나타난다
- [ ] **수정 완료** 저장 후 원래 날짜 셀에서 해당 스케줄이 **사라지고** 선택한 날짜 셀에 **나타난다**
- [ ] 달력에서 취소 클릭 시 날짜가 변경되지 않는다

### 3. 시간대 변경
- [ ] 다른 시간대 버튼 클릭 시 해당 버튼이 활성 상태(파란 배경)로 바뀐다
- [ ] **수정 완료** 저장 후 원래 시간대 슬롯에서 해당 스케줄이 **사라지고** 선택한 시간대에 **나타난다**

### 4. 날짜 + 시간대 동시 변경
- [ ] 날짜와 시간대를 모두 변경 후 저장 시 두 값이 함께 반영된다

### 5. 취소 동작
- [ ] 날짜/시간대를 변경한 후 **취소** 버튼 클릭 시 변경 사항이 사라지고 원래 값으로 돌아온다

### 6. 다른 월로 이동
- [ ] 다음 달 날짜로 변경 후 저장 시 현재 월 뷰에서 스케줄이 제거된다
- [ ] 해당 월로 이동 시 스케줄이 올바른 날짜/시간에 표시된다

### 7. 중복 배정 오류 처리
- [ ] 이미 동일인이 배정된 날짜/시간으로 변경 시 DB 오류 메시지가 표시된다

## 회귀 테스트

### 스케줄 뷰 동일 적용 확인 (CLAUDE.md 규칙)
- [ ] 월간 뷰(ScheduleGrid)에서 정상 동작
- [ ] 주간 뷰(WeekGrid)에서 날짜 변경 후 올바른 주에 표시됨
- [ ] 일간 뷰(DayView)에서 정상 동작

### 기존 수정 기능 회귀
- [ ] 이름/메모 수정 (날짜/시간 변경 없이) 여전히 정상 동작
- [ ] 역할 변경 수정 여전히 정상 동작
- [ ] 관리자가 아닌 회원의 일반 스케줄 수정(이름/메모) 여전히 정상 동작
