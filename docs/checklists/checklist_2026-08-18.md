# 2026-08-18 변경사항 점검 체크리스트

테스트 환경: http://localhost:5173
테스트 계정: 관리자 권한 계정 (SHIFT:ON, SERVE:ON, CARE:ON, WORK:ON 조직 중 하나)

---

## 1. 시간 집계 탭 — 탭 노출 조건

배경: `volunteer_hours` feature flag가 true인 버티컬(SHIFT:ON·CARE:ON·SERVE:ON·WORK:ON)에만 "시간 집계" 탭이 노출되어야 한다.

- [ ] SHIFT:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 보임
- [ ] SERVE:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 보임
- [ ] CARE:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 보임
- [ ] WORK:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 보임
- [ ] LESSON:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 **보이지 않음**
- [ ] CLASS:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 **보이지 않음**
- [ ] SALON:ON 조직 → 관리자 콘솔에 "시간 집계" 탭이 **보이지 않음**

---

## 2. 시간 집계 탭 — 기본 동작

- [ ] 탭 클릭 시 "시간 집계" 헤더와 시작일·종료일 입력 필드가 표시됨
- [ ] 기본값이 이번 달 1일~말일로 설정되어 있음
- [ ] 해당 기간에 배정 이력이 있는 경우 사용자별 테이블이 표시됨
- [ ] 테이블에 이름·참여 건수·총 시간 컬럼이 보임
- [ ] 총 시간이 "N시간" 또는 "N시간 M분" 형식으로 표시됨
- [ ] 합계 행이 테이블 하단에 표시되고 건수·시간 합산이 올바름
- [ ] 해당 기간에 배정 이력이 없는 경우 "해당 기간에 참여 이력이 없습니다." 메시지 표시

---

## 3. 시간 집계 탭 — 날짜 범위 변경

- [ ] 시작일을 변경하면 자동으로 데이터가 재조회됨
- [ ] 종료일을 변경하면 자동으로 데이터가 재조회됨
- [ ] 여러 달에 걸친 기간 지정 시 (예: 2026-01-01 ~ 2026-06-30) 누적 시간이 합산되어 표시됨
- [ ] 결과가 총 시간 기준 내림차순으로 정렬됨

---

## 4. 시간 집계 탭 — 운영 모드별 동작

- [ ] **회원 모드** 조직: 테이블에 회원 이름(프로필 기준)이 표시됨
- [ ] **비회원(방문자) 모드** 조직: 테이블에 배정 시 입력한 방문자 이름이 표시됨
- [ ] "종료(close)" 타입 배정은 집계에서 제외됨

## 5. 회귀 테스트 (기존 기능 영향 확인)

- [ ] feature flag가 꺼진 탭(예: lessons)에 직접 URL 접근 시 members 탭으로 리다이렉트됨
- [ ] 대시보드 "참여 현황" 위젯이 기존과 동일하게 작동함
