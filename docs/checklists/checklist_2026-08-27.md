## 1. 회원가입 플로우 변경 — 위자드 먼저, 이메일 인증 나중

배경: 이메일 컨펌 클릭 후 조직 위자드가 나타나면 사용자가 혼란스러움.
올바른 순서는 가입 중에 위자드를 완료하고, 이메일 인증이 마지막 단계여야 함.

### 기본 가입 흐름

- [ ] 가입 페이지에서 이메일로 계속하기 → 이름/비밀번호/연락처/선택 입력
- [ ] "내 서비스 시작하기" 선택 → 서비스명/연락처 입력 후 "계속하기" 클릭 시 위자드로 진입
- [ ] **wiz-mode**: 운영 방식(회원공유/회원개별/비회원) 카드 선택 가능
- [ ] **wiz-slots**: 시간 슬롯 선택 가능 (최소 1개 이상 선택 필수)
- [ ] **wiz-roles**: 역할 추가/삭제 가능 (없이 건너뛰기도 가능)
- [ ] wiz-roles 이후 버튼이 올바르게 표시됨:
  - lessonon/classon 버티컬: "계속하기" → wiz-lesson
  - 비회원 모드: "계속하기" → wiz-fields
  - 일반 버티컬 + 회원공유/개별: "가입 완료"
- [ ] "가입 완료" 클릭 시 "이메일을 확인해 주세요" 화면 표시
- [ ] **[DB 확인]** `auth.users` 테이블에 사용자 생성 확인
- [ ] **[DB 확인]** `tenants` 테이블에 조직 생성, `setup_completed_at` 값 설정 확인
- [ ] **[DB 확인]** `tenant_members`에 is_approved=true, role='admin'으로 등록 확인
- [ ] **[DB 확인]** `schedule_rules`에 기본 슬롯 생성 확인
- [ ] **[DB 확인]** `tenant.settings.tenant_mode`가 선택한 운영방식과 일치 확인
- [ ] **[DB 확인]** `tenant.settings.time_slots`가 선택한 슬롯과 일치 확인
- [ ] **[DB 확인]** `tenant_roles`에 추가한 역할 생성 확인 (역할 추가한 경우)

### 이메일 인증 후 진입

- [ ] 가입 이메일로 받은 인증 링크 클릭
- [ ] 로그인 화면으로 이동 후 로그인 성공
- [ ] 로그인 후 **조직 위자드 없이** 바로 `/schedule`로 진입

### 팝업 진행 표시

- [ ] 기본 단계(이름/비밀번호/연락처)에서는 상단에 점(dots) 표시 확인
- [ ] wiz-* 단계에서는 "서비스 설정 1 / N" 형식의 카운터 표시 확인
- [ ] 팝업 X 버튼 클릭 시 위자드 닫히고 가입 화면으로 복귀

## 2. lessonon/classon 버티컬 — 레슨권 등록 단계

배경: lessonon, classon은 레슨권(수업권) 등록이 가입 단계에 포함되어야 함.

- [ ] `?vertical=lessonon` URL로 진입 시 wiz-roles 이후 wiz-lesson 단계 표시
- [ ] **wiz-lesson**: 레슨권 이름/회차수/유효기간(주) 입력 후 추가 가능
- [ ] 추가된 레슨권 목록 표시 및 삭제 가능
- [ ] 레슨권 없이도 "가입 완료" 진행 가능 (선택 사항)
- [ ] **[DB 확인]** 가입 완료 후 `lesson_package_types` 테이블에 등록한 레슨권 확인
