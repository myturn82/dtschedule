## 참고 — 업데이트 배포 절차 (등록 완료 후)

코드 수정 후 업데이트 배포 시:

1. `versionCode` +1, `versionName` 올리기 (예: `"1.0"` → `"1.1"`)
2. 릴리즈 AAB 빌드 (2단계 반복)
3. Play Console → 프로덕션 → 새 출시 버전
4. AAB 업로드 → 제출
5. 업데이트 심사: **1~3시간** (기존 앱 업데이트는 빠름)
6. 사용자 기기에 자동 업데이트 적용 (Wi-Fi 시 백그라운드)
