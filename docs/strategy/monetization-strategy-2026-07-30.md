## 1. Phase 1 — 무료 플랜으로 사용자 확보

### 1-1. 무료 플랜 설계 원칙

무료 플랜은 **진짜 쓸 수 있어야** 합니다. 너무 제한하면 아무도 안 씁니다.
너무 열어두면 유료 전환 동기가 없습니다.

**핵심 원칙: 핵심 기능은 무료, 규모·편의 기능은 유료**

```
무료 플랜 (Free)               유료 플랜 (Pro/Business)
────────────────────────────   ────────────────────────
조직 1개                       조직 무제한
멤버 최대 10명                 멤버 무제한
스케줄 기본 기능               스케줄 고급 기능
레슨권 최대 3종                레슨권 무제한
광고 노출 (앱+웹)              광고 없음
이메일 지원                    우선 지원 + 전화
```

### 1-2. 무료 플랜 획득 채널

| 채널 | 웹 | 앱 | 우선순위 |
|------|----|----|---------|
| 버티컬 랜딩페이지 (LESSON:ON 등) | ✅ | — | ★★★ |
| 앱스토어 검색 노출 | — | ✅ | ★★★ |
| 인스타그램/블로그 콘텐츠 마케팅 | ✅ | ✅ | ★★☆ |
| 네이버 카페·커뮤니티 | ✅ | — | ★★☆ |
| 구글 검색 (SEO) | ✅ | — | ★☆☆ (장기) |

### 1-3. 무료 기간 중 수집할 것

광고 수익보다 이 시기에 더 중요한 것은 **데이터와 신뢰**입니다.

- 어떤 기능을 가장 많이 쓰는가 (기능 사용 이벤트 로깅)
- 어디서 이탈하는가 (온보딩 완료율)
- 어떤 오류가 자주 발생하는가 (피드백 게시판 모니터링)
- 무료 사용자가 유료로 전환하는 트리거는 무엇인가

### 2-2. 앱 광고: Google AdMob

**적용 위치 및 광고 유형:**

```
배너 광고 (Banner Ad)
┌────────────────────────┐
│  스케줄 화면            │
│  (메인 콘텐츠)          │
│                        │
│                        │
├────────────────────────┤
│  ██████████ 광고 █████  │  ← 하단 고정 배너 (320×50)
└────────────────────────┘
→ 항상 노출, 수익 낮지만 UX 영향 적음

전면 광고 (Interstitial Ad)
→ 화면 전환 시 전체 화면 광고
→ 예: 스케줄 등록 완료 후 → 광고 → 메인 화면
→ 수익 높지만 남용 시 이탈률 증가
→ 권장: 하루 최대 1~2회 노출 제한

보상형 광고 (Rewarded Ad)
→ "광고 보기 → 특정 기능 잠금 해제"
→ 예: "30초 광고 보면 이번 달 레슨권 내보내기 무료"
→ 사용자가 자발적으로 선택 → 거부감 낮음
→ B2B 앱에서 가장 적합한 방식
```

**AdMob 설정 순서:**
```
1. admob.google.com 에서 앱 등록
2. 광고 단위(Ad Unit) 생성 (배너/전면/보상형 각각)
3. npm install @capacitor-community/admob
4. capacitor.config.ts에 AdMob 앱 ID 추가
5. 무료 플랜 여부에 따라 광고 on/off 분기
```

**예상 수익 (앱, eCPM 기준):**

| 월 DAU | 배너 광고 | 전면 광고 | 합계 (예상) |
|--------|----------|----------|-----------|
| 100    | $3~5     | $10~20   | $15~25    |
| 500    | $15~25   | $50~100  | $70~130   |
| 2,000  | $60~100  | $200~400 | $270~500  |

> 앱 광고 수익도 초기엔 크지 않습니다. 사용자 확보가 선행돼야 합니다.

### 2-3. 광고 구현 — 플랜별 분기 코드 설계

```typescript
// src/hooks/useAdDisplay.ts
export function useAdDisplay() {
  const { plan } = usePlanLimits()
  
  // 유료 플랜이면 광고 완전 숨김
  const showAds = plan === 'free'
  
  return { showAds }
}

// 컴포넌트에서 사용
function SchedulePage() {
  const { showAds } = useAdDisplay()
  
  return (
    <div>
      <ScheduleGrid />
      {showAds && <AdBanner position="bottom" />}
    </div>
  )
}
```

```typescript
// src/components/ads/AdBanner.tsx
import { AdMob, BannerAdPosition } from '@capacitor-community/admob'

export function AdBanner({ position }: { position: 'bottom' | 'top' }) {
  const isNativeApp = Capacitor.isNativePlatform()
  
  useEffect(() => {
    if (isNativeApp) {
      // 앱: AdMob 배너
      AdMob.showBanner({
        adId: import.meta.env.VITE_ADMOB_BANNER_ID,
        position: BannerAdPosition.BOTTOM_CENTER,
      })
    }
    // 웹: AdSense는 script 태그로 처리
  }, [])
  
  if (!isNativeApp) {
    // 웹 AdSense 슬롯
    return <ins className="adsbygoogle" data-ad-slot="..." />
  }
  
  return null // 앱은 네이티브 레이어에서 렌더
}
```

## 3. Phase 3 — 구독 수익 (핵심)

### 3-1. 요금제 설계

```
┌─────────────────┬─────────────────┬──────────────────────┐
│   FREE           │    PRO           │    BUSINESS           │
│   무료           │    월 29,000원   │    월 79,000원        │
│                 │    (연 24,000원) │    (연 65,000원)      │
├─────────────────┼─────────────────┼──────────────────────┤
│ 조직 1개         │ 조직 3개         │ 조직 무제한           │
│ 멤버 10명        │ 멤버 50명        │ 멤버 무제한           │
│ 레슨권 3종       │ 레슨권 무제한    │ 레슨권 무제한         │
│ 광고 있음        │ 광고 없음        │ 광고 없음             │
│ 이메일 지원      │ 이메일 지원      │ 우선 지원             │
│ —               │ SMS 월 100건    │ SMS 월 500건          │
│ —               │ 통계 기본       │ 통계 고급             │
│ —               │ —               │ API 접근              │
│ —               │ —               │ 전담 온보딩           │
└─────────────────┴─────────────────┴──────────────────────┘
```

**가격 설정 근거:**
- PT 강사 1인: 월 수입 200~400만원 → 월 29,000원은 0.7~1.5% 수준 → 가격 저항 낮음
- 학원 운영: 월 수입 300~1,000만원 → 월 29,000원은 0.3~1% 수준 → 합리적
- 헬스클럽: 월 수입 500만원+ → 월 79,000원도 무리 없음

### 3-2. 결제 시스템 구현

**웹 결제 (PC/브라우저):** Stripe 또는 토스페이먼츠

```
Stripe 권장 이유:
  - 한국 원화(KRW) 지원
  - 구독(Subscription) API 내장
  - 카드·계좌이체 지원
  - 수수료: 2.9% + $0.30 (국내 카드)

토스페이먼츠 대안:
  - 한국 사용자 친숙함
  - 간편결제(카카오페이·네이버페이) 지원
  - 수수료: 카드 2.2~3.3%
```

**앱 결제 (Android/iOS):**
```
⚠️ 중요: 앱 내에서 구독 결제를 받으면 스토어 수수료 적용
  - Google Play: 15% (월 $1M 이하) / 30% (초과)
  - Apple App Store: 15% (연 $1M 이하) / 30% (초과)

선택지:
  A. 앱 내 In-App Purchase (IAP)
     → 수수료 15~30% 발생
     → 앱 심사 통과 쉬움
     → 구현 복잡

  B. 웹 결제로 유도
     → "구독은 웹사이트에서 가입하세요" 안내
     → 수수료 없음
     → Apple 정책상 앱 내 결제 링크 직접 노출 불가
     → 우회: "계정 관리" 버튼 → 브라우저로 연결

권장: Phase 3 초기엔 B 방식 (웹 결제 유도)으로 시작
     사용자가 늘면 A 방식 추가 검토
```

**핵심 전환 트리거 (한도 도달 시점에 집중):**

```typescript
// 멤버 한도 도달 시 업그레이드 모달 표시
function usePlanGate() {
  const { memberCount, plan, limits } = usePlanLimits()
  
  const isNearLimit = memberCount >= limits.maxMembers * 0.9  // 90% 도달
  const isAtLimit   = memberCount >= limits.maxMembers        // 100% 도달
  
  return { isNearLimit, isAtLimit }
}
```

## 5. SMS 발송 별도 수익화 (추가 아이디어)

레슨권 만료 SMS는 현재 구현된 기능입니다. 이를 **종량제로 수익화**할 수 있습니다.

```
무료 플랜:   월 SMS 10건 무료 → 초과 시 건당 20원
Pro 플랜:    월 SMS 100건 포함 → 초과 시 건당 15원
Business:   월 SMS 500건 포함 → 초과 시 건당 10원

원가 (Solapi·알리고 등 국내 SMS API):
  단문(SMS): 건당 8~11원
  장문(LMS): 건당 25~35원

마진: 건당 5~10원 → 소액이지만 사용량에 비례해 수익 발생
```

```
광고만으로 운영비 충당: 월 페이지뷰 약 50,000~100,000 필요
구독 수익으로 충당:     유료 조직 5~10개만 있으면 달성
```

→ **유료 조직 5개가 생기는 순간 운영비 자급자족 가능**

## 9. 핵심 원칙 요약

```
1. 광고는 "운영비 충당"이고, 구독이 "진짜 수익"이다.
   → 광고 수익에 기대를 낮추고, 구독 전환에 집중하라.

2. 무료 플랜은 진짜 쓸 수 있어야 한다.
   → 너무 좁히면 가입 자체를 안 한다.
   → 핵심 기능은 무료, 규모·편의·알림은 유료.

3. 전환 트리거는 "불편함"이 아니라 "아쉬움"이어야 한다.
   → "더 쓰고 싶은데 한도가 됐네" → 업그레이드
   → "기능이 막혀 아무것도 못 하겠네" → 이탈

4. 앱 결제 수수료(15~30%)를 피하려면 웹 결제로 유도하라.
   → 앱에서 "구독은 웹사이트에서 관리" 안내로 합법적 우회 가능.

5. 손익분기점은 생각보다 빠르다.
   → 유료 조직 5개 = 운영비 자급자족
   → 유료 조직 30개 = 월 100만원 수익 달성 가능
```
